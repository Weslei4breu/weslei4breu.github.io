# Itens de terceiros usados no site

Estes arquivos vieram do acervo de mídia do Wix (não foram enviados pelo Weslei).
A licença do Wix prevê uso em sites hospedados no próprio Wix. Foram copiados para
cá por decisão do Weslei em 21/10/2026. Se for preciso trocá-los, estes são os pontos:

| Arquivo | Onde é usado | Como trocar |
|---|---|---|
| `media/fundo-pintura.jpg` | fundo de todas as páginas, exceto as de TI (`styles.css`, `.page-bg`) | substituir o arquivo por outra imagem com o mesmo nome |
| `media/video-titulo.mp4` | vídeo dentro dos títulos laranja (`site.js`, constante `VIDEO`) | substituir o arquivo, ou apontar `VIDEO` para outro vídeo |
| `media/icone-instagram.png`, `media/icone-facebook.png` | ícones do rodapé, em todas as páginas | substituir os arquivos |
| `fonts/giants.woff2`, `fonts/giants.woff` | nome "WESLEI ABREU" no cabeçalho (`styles.css`, `@font-face` "Giants") | trocar o `@font-face`; alternativa gratuita: Bungee Shade (Google Fonts) |

Todo o resto em `media/` foi enviado pelo próprio Weslei ao Wix. `img/` contém arquivos
criados para este site (logo recortada, pasta em branco, fundo de circuito).
